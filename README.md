# Трекер подготовки к ЕГЭ 2028

Страница для ежедневного учёта часов: информатика, профильная математика, русский.
Плюс баллы пробников, обратный отсчёт до экзамена и тепловая карта всех дней подготовки.

Открыть: https://ytfoggy0-wq.github.io/ege-tracker/

## Как хранятся данные

Записи лежат в браузере того устройства, где открыта страница.
Чтобы телефон и компьютер видели одно и то же, в блоке «Синхронизация»
подключается своя база Supabase — инструкция есть прямо на странице.

Ключи базы не входят в код страницы: они вводятся один раз на каждом
устройстве и хранятся локально.
